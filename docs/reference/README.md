# Generated RTTI reference

This directory is generated from the supported `pivot.exe` 5.2.11 image. The
JSON files are machine-readable; the Markdown files are for browsing.

Do not edit these files by hand. Regenerate them from the repository root:

```text
python tools\dump_rtti.py path\to\pivot.exe --json --markdown --all-classes
```

The output contains published methods and fields for `TMainForm`, plus the
published class list discovered in the same executable. Addresses, offsets,
counts, and names are specific to that build.

- [Published RTTI catalog](CATALOG.md)
- [All published classes](CLASSES.md)
- [Machine-readable catalog](catalog.json)
- [Machine-readable class list](classes.json)
